# Model-Based Development (MBD) Projects using MATLAB & Simulink

## Overview

This repository contains a collection of **Model-Based Development (MBD)** projects developed using **MATLAB, Simulink, Stateflow, and Simscape**. The models are created primarily for learning, experimentation, and demonstrating automotive embedded control system concepts.

The objective of this repository is to bridge the gap between theoretical control algorithms and production-ready embedded software by following an MBD workflow from system modeling to code generation.
